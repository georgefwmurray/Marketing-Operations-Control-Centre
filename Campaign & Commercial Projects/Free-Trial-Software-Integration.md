## Free Trial Software Integration

Built an API at Veriforce (2025) so users can sign up for a free trial directly within the platform.

## How it works

- A user signs up for a free trial on the platform
- An API call fires from the platform to HubSpot
- HubSpot creates the lead
- The lead is passed to sales with the account number from the platform

## Result

**4% increase in lead volume** via optimised self-serve trial sign-up
