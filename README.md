## About the site

The site is built with Jekyll and hosted through GitHub Pages/Cloudflare. It uses Markdown and HTML for page content, Liquid for reusable layout behaviour, and SCSS for styling.

This is a public professional portfolio, not the complete internal technical documentation for the systems described. Detailed implementation material and supporting evidence are maintained separately for appropriate employer conversations.
